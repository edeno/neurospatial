# neurospatial — UX Review (usability, for neuroscience users)

## Overall Assessment

Rating: NEEDS_POLISH

Reviewed `276c8e2b` after Phase 4b on 2026-10-07, with two independent reviewers
and runtime first-run probes. A beginner can now reach a field using the
documented four-array call, and common errors offer useful recovery. Results
have informative reprs, ordinary tables and usable plots. Remaining scientific
documentation errors and a simulation-duration mismatch prevent a checkpoint
pass; output/accessor parity and joined recipes still need refinement. The
available October baseline was CONFUSING; no original quantitative metrics are
available. Detailed measurements and scripts are in the

## First-run experience

**First place field — workable.** Starting with recorded arrays, an environment
factory, `compute_spatial_rate(env, spikes, times, positions)` and `result.plot()`
complete the task. The lead's 60-second recording gave 78 bins, 59.99 seconds
occupancy, 5.321 Hz peak and 1.176 bits/spike information. Bare `Environment()`
raises E1006 with a factory example, explanation and correction; README and
quickstart describe what bin size, coordinates and result accessors mean.

**Mistake recovery — smooth for the tested common mistakes.** E1001 prints data
extent, bin size, threshold and concrete remedies for no active bins. A coarse
bin warns about possible units mismatch; milliseconds-valued spikes give a
100%-dropped warning naming both clocks. Incorrect position dimensionality
lists expected shapes and a Fix; `to_linear` on 2D data points to `bin_at`.
Omitted animation `frame_times` is a native keyword-only TypeError naming that
argument. The huge-grid UserWarning was captured as an exception before its
build continued. An unfitted object was not manufactured by private mutation:
documented factories are fitted and the bare constructor rejects, so that
guard itself was not separately exercised.

**Result interpretation — workable, with parity gaps.** Reprs expose bin count,
peak rate, occupancy, method and spike-window assumption. Population summaries
keep unit IDs 100–105, but `peak_firing_rate` means a maximum over units and
`n_neurons` differs from the proposed `n_units` vocabulary. Single and batch
summary tables have 4 and 9 columns respectively; pandas hides metrics behind
ellipsis at default width, attrs contain no units/thresholds, and the single
result's `to_xarray()` raises AttributeError. These are already Phase 7 tasks.
Static plots show a viridis map, coordinates and numeric Hz colorbar.

## Critical UX Issues

- [ ] **A duration request yields a different recording while metadata says
  otherwise.** `linear_track_session` returns 18.772 seconds for either a 1- or
  2-second request. A 60-second larger track produced millions of samples.
  Fix the duration contract and truthful metadata in Phase 4c.1; preserve an
  exact small reproducer rather than masking the problem by rescaling clocks
  in a downstream analysis.
- [ ] **Executable tutorials can still teach the wrong scientific
  interpretation.** Notebook 05 claims direction-specific/monotonic
  linearization; runtime instead reuses bins on a return traversal. Assembly
  docs turn standardized activity/effect-size cutoffs into uncalibrated
  significance statements. Correct those explanations and demonstrate the
  actual directional/control-based workflows in Phase 4c.2–4c.3.

## Confusion Points

- [ ] **Different decoder handoffs.** The direct decoder accepts a documented
  result-like model, but the session decoder's model argument documents an
  ndarray and its Notes ambiguously say “pass the result.” `.firing_rates`
  recovers; Phase 6b should make its two resulting paths explicit.
- [ ] **NWB navigation favors a soon-to-be-deleted bundle.** Session and
  `load_session` are prominent; a complete reader → epochs → environment →
  population recipe needs several pages. Phase 6c must update the joined
  recipe with holders, units and acquisition/analysis windows.
- [ ] **Result output differs across siblings.** Sparse single tables, dense
  versus summary tables and hidden population metrics require choosing the
  correct accessor. Keep the distinctions but complete Phase 7 parity and
  scannable units/threshold metadata.
- [ ] **The native 1D plot has an implementation error rather than a recovery
  message.** Rate computation works, then `rates.plot(0)` raises pcolormesh's
  2D-grid NotImplementedError. Add native 1D line plotting to Phase 7.
- [ ] **Events can have different cohorts across outputs.** A correctly
  filtered PSTH does not expose its retained-event mask, while rasters and
  position tables still include all input events. Phase 6b needs a shared
  full-window selection example and explicit boundary semantics.

## Suggested Improvements

**High**

- [ ] Implement Phase 4c's bounded duration and interpretation corrections,
  then repeat these journeys before starting Phase 5a.
- [ ] Preserve the four-array path and automatic gap handling during later
  signature and holder changes; no additional facade or mandatory bundle is
  needed to address the observed problems.

**Medium**

- [ ] Add a count-based population-statistics workflow, stable common-unit
  preprocessing and public navigation in Phase 6a.
- [ ] Complete existing Phase 7 summary/units/threshold parity and add native
  1D field plotting. Keep shared occupancy measured once per recording.
- [ ] Show analysis epochs, recording windows, actual decoder times and
  position overlays together. Label subsampled/gapped animations with
  session timestamps rather than only frame numbers.

**Low**

- [ ] Explain that HTML colorbar keywords are currently unimplemented;
  a labeled static plot can accompany an animation. Implementing animation
  colorbars is optional polish, not evidence of a failed supported contract.
- [ ] Apply Why/Fix wording proportionately to remaining small validation
  errors. Ordinary missing-argument messages already name the missing input.

## Good UX Patterns (keep)

- Factory errors coach the next call, with concrete values and links.
- Raw arrays and ordinary pandas/NumPy outputs work without mandatory bundles.
- Unit IDs survive readers and population tables; eager NWB arrays remain
  usable after HDF5 closes.
- Gaps and epoch selection work without hand-slicing temporal streams.
- Per-unit plot selection has a clear error and a one-call correction.
- Default viridis plots and generated HTML focus styling, semantic controls,
  keyboard handlers and accessible names are useful. Markup/image inspection
  was performed; interactive assistive-technology behavior was not tested.
